# controle-de-avisos
Front-end de um sistema de controle de avisos corporativos, desenvolvido para a disciplina de Front-end com HTML, CSS e JavaScript. Permite criar e agendar avisos, definir destinatários, datas e canais de comunicação, aprovar ou rejeitar, publicar, acompanhar entregas e leitura, e confirmar a leitura como destinatário.
